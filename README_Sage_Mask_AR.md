# Sage Mask Face AR

- `blender_face_mask.py`: Run inside Blender to create and export `face_mask_ar.glb`.
- `face_ar.html`: MindAR + A-Frame face tracking page.
- Upload the generated `face_mask_ar.glb` beside `face_ar.html` in the same GitHub Pages folder.

## Use
1. Blender > Scripting > Open `blender_face_mask.py` > Run Script.
2. Upload the generated `face_mask_ar.glb` to the repository.
3. Enable GitHub Pages and open `face_ar.html` over HTTPS on a phone/tablet.
4. Allow camera access and use on-screen buttons to tune size/height.

The face anchor/transform may need tuning on a real device. This is a stylized mask overlay, not a face-mesh texture.
